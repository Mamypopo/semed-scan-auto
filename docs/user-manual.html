0.1 โปรแกรมนี้ทำอะไรได้

SEMed Scanner เป็นโปรแกรมบนเครื่อง Windows สำหรับ ยิงบาร์โค้ดของผู้ป่วย ที่จุดตรวจ แล้วส่งผลไปบันทึกในระบบหลักของ SEMed ทันที โปรแกรมทำงานได้ 2 โหมด

โหมดใช้เมื่อผลที่เกิดขึ้น
Checkpointเจ้าหน้าที่หน้างานยิงบาร์โค้ดผู้ป่วยที่จุดตรวจ เช่น X-rayบันทึกว่าผู้ป่วยเข้ารับการตรวจที่จุดนั้นแล้ว (ดูบทที่ 3)
Lab Recheckห้อง Lab ยิงบาร์โค้ดตัวอย่างที่ส่งมาถึง เพื่อยืนยันว่าตัวอย่างมาถึงจริงเปลี่ยนสถานะรายการเป็น “Lab รับแล้ว” และแสดงสรุปว่าเหลือรอกี่ราย (ดูบทที่ 4)

นอกจากนี้ยังมีส่วนเสริม: เพิ่ม/ลบ หมายเหตุจุดตรวจ ของผู้ป่วยแต่ละราย (บทที่ 5), การแจ้งเตือนมุมจอ/เสียง/แผง logs (บทที่ 6), และการอัพเดทโปรแกรมอัตโนมัติ

0.2 สัญลักษณ์ที่ใช้ในคู่มือ

เคล็ดลับ (tip)วิธีที่ทำให้ทำงานเร็วขึ้นหรือพลาดน้อยลง
ข้อควรระวัง (warn)สิ่งที่ทำให้ผลไม่ตรงที่คาด หรือทำให้ต้องทำซ้ำ
หมายเหตุ (note)ข้อมูลประกอบเพิ่มเติม รวมถึงจุดที่คู่มือ “ยังไม่ยืนยัน”
อันตราย / ย้อนกลับไม่ได้ (danger)การกระทำที่ลบหรือย้อนคืนไม่ได้
  • ข้อความแบบนี้ คือข้อความ ชื่อปุ่ม หรือชื่อเมนูที่ปรากฏบนหน้าจอจริง (คัดจากโค้ดของโปรแกรม)
  • SCAN_CREATE คือ รหัสสิทธิ์ ที่ต้องมีจึงทำงานนั้นได้ (ดูข้อ 0.3)
  • ภาพประกอบทุกภาพเป็น ภาพจำลอง วาดตามโครงสร้างหน้าจอในโค้ด ข้อมูลในภาพ (ชื่อผู้ป่วย เลข CN ฯลฯ) เป็นข้อมูลสมมติ ตัวเลขสีแดงในภาพตรงกับรายการใต้ภาพ

0.3 ทำไมสิทธิ์ของแต่ละคนไม่เหมือนกัน

สิทธิ์ถูกกำหนดที่ระบบหลักตาม บทบาท ของบัญชี ไม่ได้ตั้งในโปรแกรมนี้ โปรแกรมจะส่งคำขอไปให้ระบบหลักตรวจสิทธิ์ทุกครั้ง หากบัญชีของคุณไม่มีสิทธิ์ ระบบจะปฏิเสธและแสดงข้อความ เช่น “คุณไม่มีสิทธิ์ SCAN_CREATE” ดูตารางสิทธิ์ทั้งหมดในภาคผนวก A

หมายเหตุโปรแกรมนี้ ไม่มีหน้าจอผู้ดูแลระบบ (จัดการผู้ใช้ บทบาท สิทธิ์ ประกาศ) การทำงานเหล่านั้นอยู่ในระบบเว็บหลักของ SEMed ซึ่งไม่อยู่ในโค้ดที่ใช้เขียนคู่มือนี้ จึงไม่ได้เขียนบทผู้ดูแลระบบไว้ หากต้องการ ควรทำคู่มือแยกจากระบบหลัก

0.4 ข้อกำหนดเครื่อง

  • เครื่อง Windows ที่ติดตั้งโปรแกรม SEMed Scanner และต่อเครือข่ายถึงระบบหลักได้
  • เครื่องสแกนบาร์โค้ดแบบ USB ที่ทำงานเหมือนคีย์บอร์ด (ยิงแล้วพิมพ์ตัวอักษรตามด้วย Enter) — โค้ดรับข้อมูลจากคีย์บอร์ดโดยตรง ไม่ต้องตั้งค่าไดรเวอร์พิเศษ
  • บัญชีผู้ใช้ SEMed (อีเมล/รหัสผ่าน หรือบัญชี Microsoft)

1เข้าสู่ระบบและรู้จักหน้าจอ

1.1 เข้าสู่ระบบ

วัตถุประสงค์: ยืนยันตัวตนก่อนใช้งาน สิทธิ์ที่ต้องมี: บัญชีที่ใช้งานได้ (ไม่ถูกปิด ไม่หมดอายุ)

ขั้นตอน (อีเมลและรหัสผ่าน)

  1. เปิดโปรแกรม SEMed Scanner จะเห็นหน้า เข้าสู่ระบบ
  2. กรอก อีเมล และ รหัสผ่าน (กดไอคอนรูปตาเพื่อดูรหัสที่พิมพ์)
  3. ติ๊ก จดจำฉันไว้ หากต้องการ
  4. กด เข้าสู่ระบบ ปุ่มจะเปลี่ยนเป็น “กำลังเข้าสู่ระบบ...” แล้วมีข้อความ “ยินดีต้อนรับ …” มุมขวาบน

ขั้นตอน (บัญชี Microsoft)

  1. กด เข้าสู่ระบบด้วย Microsoft จะมีหน้าต่าง Microsoft Login เปิดขึ้น
  2. ล็อกอินตามขั้นตอนของ Microsoft เมื่อสำเร็จหน้าต่างจะปิดเอง และเข้าสู่หน้าหลัก
  3. หากปิดหน้าต่างก่อนเสร็จ จะแจ้ง “ปิดหน้าต่างก่อนเข้าสู่ระบบ”

ข้อควรระวังบัญชีที่ผูกกับ Microsoft จะล็อกอินด้วยรหัสผ่านไม่ได้ ระบบจะแจ้งให้กดปุ่ม “เข้าสู่ระบบด้วย Microsoft” แทน

1.2 โครงสร้างหน้าจอหลัก

หน้าต่างโปรแกรมมีขนาดเริ่มต้น 480×700 พิกเซล (เล็กสุด 400×600) เมื่อเข้าสู่ระบบแล้วจะเห็นแถบบนสุดตลอดเวลา และเนื้อหาด้านล่างเลื่อนขึ้นลงได้

ส่วนแสดงอะไร
แถบบนสุด (ซ้าย)โลโก้ S, ชื่อ SEMed Scanner และเลขเวอร์ชัน (เช่น v1.2.0)
แถบบนสุด (ขวา)จุดสีเขียว + ชื่อผู้ใช้ที่ล็อกอิน และปุ่มไอคอนออกจากระบบ (วางเมาส์เหนือปุ่มจะขึ้น “ออกจากระบบ”)
แถบอัพเดทปรากฏเมื่อมีเวอร์ชันใหม่ (ดูข้อ 6.4)
เนื้อหาครั้งแรกให้เลือกโหมด จากนั้นแสดงหน้าทำงานของโหมดนั้น

1.3 ออกจากระบบ

กดปุ่มไอคอนมุมขวาบน จะมีข้อความ “ออกจากระบบสำเร็จ” และล้างค่าที่จำไว้ทั้งหมดของเครื่องนี้ (โหมด จุดตรวจ CNGroup) ต้องเลือกใหม่เมื่อเข้าใช้อีกครั้ง

1.4 เซสชันหมดอายุ

หากระหว่างสแกนระบบหลักตอบว่าการเข้าสู่ระบบหมดอายุ โปรแกรมจะพาออกจากระบบอัตโนมัติและแสดงกล่อง หมดอายุการใช้งาน พร้อมข้อความ “กรุณาเข้าสู่ระบบใหม่” กด ตกลง แล้วล็อกอินใหม่

เคล็ดลับเมื่อเปิดโปรแกรมใหม่ โปรแกรมจะตรวจ token ที่เก็บไว้ หากยังใช้ได้จะเข้าหน้าหลักเลยโดยไม่ต้องกรอกรหัสอีก

2ตั้งค่าก่อนเริ่มงาน

ก่อนสแกนต้องเลือก 3 อย่างตามลำดับ: โหมด → CNGroup → จุดตรวจ โปรแกรมจำค่าเหล่านี้ไว้ให้เครื่องนี้ ไม่ต้องเลือกซ้ำทุกครั้งที่เปิดโปรแกรม

2.1 เลือกโหมดการทำงาน

  1. เมื่อเข้าสู่ระบบครั้งแรกจะเห็นการ์ด เลือกโหมดการทำงาน พร้อมข้อความ “เลือกครั้งเดียว ระบบจะจำไว้ให้เครื่องนี้ (เปลี่ยนภายหลังได้)”
  2. กด Checkpoint (สแกนหน้างาน เช่น X-ray) หรือ Lab Recheck

เปลี่ยนโหมดภายหลัง

กดลิงก์ เปลี่ยนโหมด ที่มุมขวาของบรรทัด “โหมด: …” จะมีกล่องยืนยัน เปลี่ยนโหมดการทำงาน?

ข้อควรระวังข้อความในกล่อง: “จะล้างจุดตรวจและ CNGroup ที่เลือกไว้ทั้งหมด ต้องเลือกใหม่หลังเปลี่ยน” กด เปลี่ยนโหมด เพื่อยืนยัน หรือ ยกเลิก เพื่อกลับ

2.2 เลือก CNGroup

CNGroup คือกลุ่มผู้เข้ารับบริการที่จะสแกนในรอบนี้ (เช่น กลุ่มตรวจสุขภาพของบริษัทหนึ่ง) จำเป็นต้องเลือกทั้งสองโหมด ไม่เช่นนั้นสแกนไม่ได้

  1. กดปุ่ม CNGroup (มุมขวาของแถวที่แสดงชื่อ CNGroup) แผงเลือกจะเปิดขึ้น
  2. พิมพ์ในช่อง ค้นหา CNGroup... เพื่อกรองรายการ (ค้นหาอัตโนมัติหลังหยุดพิมพ์ประมาณ 0.3 วินาที)
  3. คลิกชื่อ CNGroup ที่ต้องการ แผงจะปิดเอง และชื่อแสดงเป็นป้ายสีน้ำเงิน เช่น “ตรวจสุขภาพ บริษัท A (CN-A01)” ปุ่ม CNGroup จะมีเครื่องหมาย ✓ สีเขียว

หากยังไม่เลือก จะเห็นข้อความ “ยังไม่ได้เลือก CNGroup” และแถบเตือนสีเหลือง “กรุณาเลือก CNGroup ก่อนสแกน” พร้อมลิงก์ เลือก ถ้าไม่พบรายการจะแสดง “ไม่พบ CNGroup”

2.3 เลือกจุดตรวจ

  1. กดปุ่ม จุดตรวจ แผง เลือกจุดตรวจ จะเปิดขึ้น
  2. พิมพ์ใน ค้นหาจุดตรวจ... เพื่อกรอง
  3. คลิกแถวของจุดตรวจเพื่อ ติ๊กเลือก/ยกเลิก เลือกได้หลายจุดพร้อมกัน ตัวเลขบนปุ่มและข้อความ “เลือก N จุด” จะอัพเดททันที
  4. กด จุดตรวจ อีกครั้งเพื่อปิดแผง ป้ายสีน้ำเงินของจุดที่เลือกจะแสดงในแถว
  • ล้างทั้งหมด (ปุ่มสีแดง ปรากฏเมื่อมีจุดที่เลือก) ยกเลิกการเลือกทั้งหมดในครั้งเดียว
  • ป้าย พิเศษ คือจุดตรวจที่ระบบหลักระบุว่าเป็นจุดพิเศษ
  • หากไม่พบ จะขึ้น “ไม่พบจุดตรวจ”
โหมดเลือกจุดตรวจข้อความเมื่อยังไม่เลือก
Checkpointบังคับแถบเตือนสีเหลือง “กรุณาเลือกจุดตรวจก่อนสแกน”
Lab Recheckไม่บังคับแถบสีเทา “ยังไม่ได้เลือกจุดตรวจ — ไม่บังคับ แต่ช่วยกันสแกนผิดจุดได้ถ้าเลือกไว้”
เคล็ดลับเลือกจุดตรวจเฉพาะที่เครื่องนี้รับผิดชอบเท่านั้น จุดที่เลือกทำหน้าที่เป็น “รายการที่อนุญาต” หากยิงบาร์โค้ดของจุดอื่น โปรแกรมจะปฏิเสธ ช่วยกันสแกนผิดจุด
หมายเหตุชื่อจุดตรวจ/CNGroup ที่ค้นหาอัตโนมัติจะโหลดจากระบบหลัก หากเครือข่ายขัดข้องรายการจะว่าง และแผง logs จะมีข้อความ “โหลดจุดตรวจล้มเหลว” หรือ “โหลด CNGroup ล้มเหลว”

3โหมด Checkpoint (สแกนหน้างาน)

วัตถุประสงค์: บันทึกว่าผู้ป่วยมาตรวจที่จุดตรวจนี้แล้ว สิทธิ์ที่ต้องมี: SCAN_CREATE (สแกน) และ SCAN_DELETE (ยกเลิกการสแกน)

3.1 ภาพรวมหน้าจอ

ภาพจำลอง: ลำดับการ์ดและข้อความตรงกับโค้ด แต่ขนาด สี และระยะห่างอาจต่างจากหน้าจอจริงเล็กน้อย

3.2 รูปแบบบาร์โค้ด

บาร์โค้ดที่โปรแกรมรับต้องเป็นรูปแบบ CN.รหัสจุดตรวจ เช่น 691220014.16 หมายถึง CN 691220014 ที่จุดตรวจรหัส 16 โปรแกรมแยกตัวเลขหลังจุดสุดท้ายเป็นรหัสจุดตรวจ

ต้องมีรหัสจุดตรวจในบาร์โค้ดบาร์โค้ดที่ไม่มีจุด “.” จะถูกปฏิเสธด้วยข้อความ “กรุณาระบุ Station ID ในบาร์โค้ด (CN.STATION_ID)” และไม่มีการบันทึกใดๆ

3.3 สถานะ “พร้อมรับการสแกน”

การ์ดสถานะสีน้ำเงินแสดง พร้อมรับการสแกน / “สแกนบาร์โค้ดผู้ป่วยได้เลย” เมื่อเลือก จุดตรวจอย่างน้อย 1 จุดและ CNGroup แล้ว หากยังไม่ครบจะเป็นการ์ดสีขาว ยังไม่พร้อม / “เลือกจุดตรวจก่อน” ป้าย Checkup ทางขวาเป็นป้ายแสดงประเภทการสแกน (ไม่ใช่ปุ่ม)

หมายเหตุข้อความใต้ “ยังไม่พร้อม” พูดถึงเฉพาะจุดตรวจ แต่ถ้าเลือกจุดตรวจแล้วและยังไม่ได้เลือก CNGroup การ์ดก็ยังเป็น “ยังไม่พร้อม” เช่นกัน ให้ดูแถบเตือนสีเหลืองประกอบ

3.4 วิธีสแกน

  1. ตรวจว่าการ์ดสถานะเป็น พร้อมรับการสแกน
  2. ยิงบาร์โค้ดด้วยเครื่องสแกน โปรแกรมรับข้อมูลได้ แม้หน้าต่างโปรแกรมไม่ได้อยู่ด้านหน้า (ดักคีย์บอร์ดทั้งเครื่อง)
  3. หรือพิมพ์รหัสในช่อง พิมพ์หรือสแกน barcode แล้วกด Enter หรือปุ่ม สแกน
  4. ดูผลที่การ์ด ผลล่าสุด, แจ้งเตือนมุมขวาล่างของจอ และรายการใน ประวัติ

โหมดป้อนข้อมูล Auto / Manual

ในการ์ดสแกนมีปุ่มสลับ Auto และ Manual ปัจจุบัน ปุ่ม Auto ถูกปิดใช้งานชั่วคราว (วางเมาส์จะขึ้น “ปิดใช้งานชั่วคราว: auto mode”) และโปรแกรมตั้งเป็น Manual ทุกครั้งที่เปิด ซึ่งหมายความว่า:

  • ต้องเลือกจุดตรวจในแอปก่อน
  • จุดตรวจที่ฝังในบาร์โค้ดต้อง ตรงกับจุดที่เลือกไว้ในแอป มิฉะนั้นปฏิเสธ
  • เลือกหลายจุดได้ แต่แต่ละการสแกนจะส่งไปที่จุดตรวจที่ฝังในบาร์โค้ดจุดเดียว
ข้อควรระวัง: ความเร็วการยิงโปรแกรมแยก “เครื่องสแกน” ออกจาก “คนพิมพ์” ด้วยความเร็ว: ตัวอักษรต้องมาต่อเนื่องห่างกันไม่เกิน 50 มิลลิวินาที และต้องยาวอย่างน้อย 5 ตัวอักษร จึงจะถือเป็นบาร์โค้ด การพิมพ์ด้วยมือในที่อื่นจึงไม่ทำให้เกิดการสแกน แต่การพิมพ์ในช่อง “พิมพ์หรือสแกน barcode” แล้วกด Enter ใช้ได้เสมอ
เคล็ดลับยิงบาร์โค้ดเดิมซ้ำภายใน 1 วินาทีจะถูกข้ามเป็นการกันยิงซ้ำสองครั้ง ไม่ขึ้นผลซ้ำ
หมายเหตุ: อักขระที่รับตัวดักคีย์บอร์ดเบื้องหลังในโค้ดรับเฉพาะตัวอักษร A–Z ตัวเลข 0–9 (รวมแป้นตัวเลข) และจุด “.” อักขระอื่น เช่น “-” หรือ “/” จะไม่ถูกรับ หากป้ายบาร์โค้ดมีอักขระเหล่านี้ให้พิมพ์ในช่อง “พิมพ์หรือสแกน barcode” แทน (ยังไม่ได้ทดสอบกับเครื่องสแกนจริง)

3.5 อ่านผลการสแกน

ป้ายความหมายต้องทำอะไร
ใหม่ (เขียว)บันทึกการตรวจครั้งแรกที่จุดนี้สำเร็จไม่ต้องทำอะไร
ซ้ำ (เหลือง)ผู้ป่วยเคยถูกสแกนที่จุดนี้แล้ว ข้อความบอกเวลาและผู้สแกนเดิมตรวจว่ายิงผู้ป่วยถูกคนหรือไม่ ไม่มีการบันทึกซ้ำ
ผิดพลาด (แดง)สแกนไม่สำเร็จ ข้อความสีแดงบอกสาเหตุดูข้อความและตารางภาคผนวก B
ยกเลิกแล้ว (เทา)การสแกนที่ถูกยกเลิก ชื่อมีเส้นขีดฆ่ายิงใหม่ได้ถ้ายิงผิดโดยไม่ได้ตั้งใจ

การ์ดผลแสดง ชื่อ-สกุล, HN, CN, แผนก · บริษัท, ชื่อจุดตรวจ, เวลา และข้อความจากระบบหลัก (ถ้ามี)

3.6 ยกเลิกการสแกน SCAN_DELETE

  1. กดปุ่ม ยกเลิก สีแดงที่การ์ด “ผลล่าสุด” — หรือในแถวของ “ประวัติ” (ปุ่มนี้ ปรากฏเมื่อเลื่อนเมาส์ไปที่แถว)
  2. กล่อง ยืนยันการยกเลิก แสดงชื่อผู้ป่วยและเวลา
  3. กด ยกเลิกการสแกน เพื่อยืนยัน หรือ ปิด เพื่อกลับ
  4. สำเร็จ: แจ้งเตือน “🚫 ยกเลิกสแกน” และแถวกลายเป็น “ยกเลิกแล้ว”
ย้อนกลับในโปรแกรมไม่ได้เมื่อยกเลิกแล้ว ปุ่มยกเลิกหายไป หากยกเลิกผิด ให้ยิงบาร์โค้ดนั้นใหม่ (ระบบมีกรณียกเลิกแล้วสแกนใหม่ ซึ่งข้อความจะถูกแจ้งจากระบบหลัก)

ข้อความที่อาจพบ: “การสแกนนี้ถูกยกเลิกไปแล้ว”, “ไม่พบข้อมูลการสแกน”, “ยกเลิกไม่สำเร็จ” (ดูภาคผนวก B)

3.7 ประวัติการสแกน

  • แสดง 20 รายการล่าสุด ของการเปิดโปรแกรมครั้งนี้ จุดสีเขียว = สำเร็จ, แดง = ผิดพลาด, เทา = ยกเลิก
  • กด ล้าง เพื่อล้างประวัติและผลล่าสุดบนหน้าจอ (ไม่ได้ลบข้อมูลในระบบหลัก)
  • ประวัติหายเมื่อปิดโปรแกรม ไม่ได้เก็บไว้ในเครื่อง

4โหมด Lab Recheck

วัตถุประสงค์: ห้อง Lab ยืนยันว่าตัวอย่างของผู้ป่วยมาถึงจริง โดยเทียบกับรายการที่หน้างานยิงไว้แล้ว สิทธิ์ที่ต้องมี: SCAN_CREATE (ยิง recheck), SCAN_UPDATE (ยกเลิก recheck), SCAN_READ (ดูสรุป)

4.1 เตรียมก่อนเริ่ม

  1. เลือกโหมด Lab Recheck (ข้อ 2.1)
  2. เลือก CNGroup (บังคับ) ช่องยิงจะถูกปิดและขึ้น “กรุณาเลือก CNGroup ก่อน” จนกว่าจะเลือก
  3. เลือกจุดตรวจ (ไม่บังคับ) ถ้าเลือก โปรแกรมจะตรวจว่าจุดในบาร์โค้ดอยู่ในรายการที่เลือกก่อนส่ง ช่วยกันยิงผิดจุด

4.2 ยิง Recheck

  1. ยิงบาร์โค้ดรูปแบบ CN.STATION_ID ด้วยเครื่องสแกน หรือพิมพ์ในช่อง ยิงบาร์โค้ดแล้วกด Enter... (CN.STATION_ID) แล้วกด Enter
  2. ดูผลในรายการ ประวัติ Recheck และการแจ้งเตือนมุมจอ
  3. ตัวเลขสรุปด้านบนอัพเดทอัตโนมัติหลัง recheck สำเร็จครั้งใหม่
ป้ายในประวัติความหมาย
สำเร็จrecheck ครั้งแรกสำเร็จ — ข้อความ “recheck สำเร็จ”
ซ้ำเคย recheck แล้ว — ข้อความ “recheck แล้ว เมื่อ HH:MM”
ผิดพลาดถูกปฏิเสธ มีข้อความสีแดงใต้แถว
ยกเลิกรายการที่ยกเลิก recheck แล้ว (แถวจางลง ชื่อขีดฆ่า)

4.3 อ่านสรุป “สรุป CNGroup นี้”

กล่องความหมาย
ทั้งหมดจำนวนผู้ป่วยทั้งหมดใน CNGroup
รอเช็คจำนวนที่ยัง “รอ Lab รับ”
Lab รับแล้วจำนวนที่ recheck แล้ว
รายการต่อจุดตรวจแสดง รอ N / ทั้งหมด ถ้าเหลือ หรือ ครบ / ทั้งหมด (สีเขียว) เมื่อไม่เหลือ

4.4 ยกเลิก recheck SCAN_UPDATE

  1. กดปุ่ม ยกเลิก ที่แถวใน “ประวัติ Recheck” (มีเฉพาะแถว สำเร็จ/ซ้ำ)
  2. กล่อง ยืนยันการยกเลิก recheck → กด ยกเลิก recheck หรือ ปิด
  3. สำเร็จ: แถวเปลี่ยนเป็น “ยกเลิก” และตัวเลขสรุปรีเฟรช ล้มเหลว: กล่อง ยกเลิกไม่สำเร็จ
หมายเหตุไม่สามารถยกเลิกรายการที่ “ยังไม่ได้ recheck” (ข้อความ “ยังไม่ได้ recheck ไม่สามารถยกเลิกได้”)

4.5 เมื่อ recheck ถูกปฏิเสธ

Lab สร้างรายการเองไม่ได้ หากไม่มีการยิงจากหน้างานมาก่อน ระบบจะปฏิเสธและ บันทึกเป็นรายการผิดปกติ ให้ทะเบียน/หน้างานตามตรวจสอบ ผู้ใช้ไม่ต้องทำอะไรเพิ่มในโปรแกรม ให้แจ้งหน้างานตามข้อความ

ข้อความแปลว่า / ทำอย่างไร
ไม่พบ CN "…" ในระบบ (CNGroup ที่เลือก)บาร์โค้ดอาจมาจากคนละ CNGroup/รอบ ตรวจว่าเลือก CNGroup ถูกต้อง
ไม่พบ registration CHECKUP สำหรับ CN นี้ผู้ป่วยยังไม่มีการลงทะเบียนตรวจ แจ้งทะเบียน
ไม่พบจุดตรวจหรือจุดตรวจถูกปิดใช้งานรหัสจุดตรวจในบาร์โค้ดผิดหรือถูกปิด
"…" ไม่ใช่จุดตรวจ LABยิงบาร์โค้ดของจุดที่ไม่ใช่ Lab ผิดใบ
ไม่พบการยิงจากหน้างานสำหรับ "…" กรุณาแจ้งหน้างาน/ทะเบียนให้ตรวจสอบหน้างานยังไม่ได้ยิงหรือยิงผิดรายการ แจ้งหน้างาน
จุดตรวจไม่ตรงกัน: บาร์โค้ดนี้เป็นของจุดตรวจ #… แต่ไม่อยู่ในรายการที่เลือกตรวจรายการจุดตรวจที่เลือกไว้ในแอป

5หมายเหตุจุดตรวจ

วัตถุประสงค์: บันทึกหมายเหตุของผู้ป่วยรายหนึ่งที่จุดตรวจหนึ่ง เช่น เหตุผลที่ไม่ได้ตรวจ เมนู: การ์ด เพิ่มหมายเหตุ ล่างสุดของหน้า โหมด Checkpoint เท่านั้น (ไม่มีในโหมด Lab Recheck) สิทธิ์: STATION_REMARK_CREATE STATION_REMARK_DELETE REMARK_REASON_READ

5.1 ค้นหาผู้ป่วย

  1. พิมพ์ในช่อง CN.จุดตรวจ เช่น 691220014.16 ตามรูปแบบ CN.รหัสจุดตรวจ
  2. กด Enter หรือปุ่มไอคอนแว่นขยาย
  3. หากมีหมายเหตุเดิม จะมีกล่อง มีหมายเหตุอยู่แล้ว แสดงเหตุผลและข้อความเดิม กด แก้ไขหมายเหตุ เพื่อไปแก้

ผลค้นหาแสดง ชื่อ, HN, CN, ป้าย มีรายการตรวจ / ไม่มีรายการตรวจ, รหัสพนักงาน/ตำแหน่ง/แผนก/บริษัท (เท่าที่มี), ชื่อจุดตรวจ และรายการตรวจที่จุดนั้น

5.2 บันทึกหมายเหตุ

ส่วนบันทึกจะปรากฏ เฉพาะเมื่อป้ายเป็น “มีรายการตรวจ”

ช่องบังคับหมายเหตุ
CN.จุดตรวจ (ช่องค้นหา)*รูปแบบ CN.รหัสจุดตรวจ ถ้าผิดรูปแบบขึ้น “รูปแบบไม่ถูกต้อง”
เหตุผล (รายการเลือก)ไม่บังคับตัวเลือกแรก “-- เลือกเหตุผล (ไม่บังคับ) --”
หมายเหตุเพิ่มเติมไม่บังคับข้อความอิสระ

กด บันทึกหมายเหตุ สำเร็จจะขึ้น “บันทึกหมายเหตุสำเร็จ” (ปิดเองใน 2 วินาที) และปุ่ม ลบ จะปรากฏทันที

หมายเหตุโค้ดไม่ได้บังคับให้เลือกเหตุผลหรือกรอกข้อความ จึงบันทึกหมายเหตุว่างได้ (ยังไม่ยืนยันว่าระบบหลักยอมรับค่าว่างทั้งสองช่องหรือไม่)

5.3 ลบหมายเหตุ

  1. ค้นหาผู้ป่วยที่มีหมายเหตุอยู่ แล้วกด ลบ
  2. กล่อง ยืนยันการลบหมายเหตุ ระบุชื่อผู้ป่วยและจุดตรวจ → กด ลบ หรือ ยกเลิก
  3. สำเร็จ: “ลบหมายเหตุสำเร็จ” และฟอร์มถูกล้าง
ลบแล้วกู้คืนไม่ได้ต้องพิมพ์หมายเหตุใหม่เองหากลบผิด

5.4 ข้อความที่พบบ่อย

ข้อความวิธีแก้
รูปแบบไม่ถูกต้อง — กรุณาพิมพ์ในรูปแบบ CN.จุดตรวจ เช่น 691220014.16ใส่จุด “.” และรหัสจุดตรวจเป็นตัวเลขต่อท้าย
ไม่พบผู้ป่วย — ไม่พบผู้ป่วยจาก CN นี้ในจุดตรวจที่เลือกตรวจเลข CN และรหัสจุดตรวจ
บันทึกไม่สำเร็จ / ลบไม่สำเร็จอ่านข้อความใต้หัวข้อ มักเป็นเรื่องสิทธิ์หรือเครือข่าย
หมายเหตุ (ยังไม่ยืนยัน)โค้ดสั่ง “หยุดรับสแกน” ชั่วคราวขณะที่เคอร์เซอร์อยู่ในช่องเลือกเหตุผล/หมายเหตุ เพื่อไม่ให้การพิมพ์ถูกนับเป็นสแกน ยังไม่ได้ทดสอบการทำงานจริงของฟังก์ชันนี้ หากพิมพ์หมายเหตุแล้วพบว่ามีการสแกนแทรกขึ้นมา ให้แจ้งผู้พัฒนา

6การแจ้งเตือน เสียง และ logs

6.1 แจ้งเตือนมุมขวาล่างของจอ

ทุกผลการสแกนมีกล่องแจ้งเตือนเล็กๆ ลอยที่ มุมขวาล่างของหน้าจอหลัก อยู่ประมาณ 1.5 วินาทีแล้วหายเอง ลอยเหนือโปรแกรมอื่น และแสดงพร้อมกันได้สูงสุด 3 กล่อง (กล่องเก่าสุดถูกปิดก่อน) หัวข้อที่พบ:

หัวข้อเมื่อไร
✅ สแกนสำเร็จสแกนใหม่สำเร็จ แสดง ผู้ป่วย / CN / จุดตรวจ
🔁 สแกนซ้ำเคยสแกนที่จุดนี้แล้ว
⛔ จุดตรวจไม่ตรงกันจุดในบาร์โค้ดไม่อยู่ในรายการที่เลือก
⛔ รูปแบบไม่ถูกต้องบาร์โค้ดไม่มี Station ID

เคล็ดลับกล่องแจ้งเตือนหายเร็วมาก หากพลาดข้อความ ให้เปิดแผง logs ในหน้าโปรแกรม (ข้อ 6.3) ซึ่งเก็บข้อความครบทุกรายการ

6.2 เสียงแจ้งเตือน

เสียงเล่นตามผล (สำเร็จ / ซ้ำ / ผิดพลาด) เฉพาะเมื่อเครื่องถูกตั้งค่าเปิดเสียง (ตัวแปร ENABLE_SOUND=true ในไฟล์ .env ของโปรแกรม) ผู้ใช้ทั่วไปเปลี่ยนค่านี้เองไม่ได้ในหน้าจอ หากไม่มีเสียง ให้แจ้งผู้ดูแลเครื่อง

6.3 แผง logs

การ์ด logs ในหน้าหลัก กดที่หัวการ์ดเพื่อเปิด/ปิด แสดงประวัติเหตุการณ์ล่าสุดก่อน แต่ละบรรทัดมีจุดสี เวลา และข้อความ

สีจุดระดับตัวอย่าง
เขียวsuccessสแกนสำเร็จ: นาย …
ฟ้าinfoManual scan: "…", โหลดจุดตรวจ: N รายการ, Token OK
เหลืองwarnToken verify ล้มเหลว
แดงerror❌ เกิดข้อผิดพลาด: … [สถานะ], Scanner worker หยุดทำงาน
  • ป้ายแดง N err ข้างหัวข้อ logs นับจำนวน error และเมื่อมี error ใหม่ แผงจะเปิดเองอัตโนมัติ
  • กด ล้าง (เมื่อเปิดแผงอยู่) เพื่อล้างรายการ
  • เมื่อต้องแจ้งปัญหากับผู้ดูแล ให้ถ่ายภาพแผง logs ส่งไปด้วย
ข้อควรระวังlogs อาจมีชื่อผู้ป่วยและเลข CN ไม่ควรส่งภาพให้บุคคลภายนอก

6.4 อัพเดทโปรแกรม

หลังเปิดโปรแกรมประมาณ 3 วินาที โปรแกรมตรวจหาเวอร์ชันใหม่เอง (ไม่ตรวจในโหมดนักพัฒนา) จะมีแถบใต้แถบบนสุด:

  1. พบเวอร์ชันใหม่ x.y.z → กด ดาวน์โหลด
  2. ดาวน์โหลดอัพเดท N% รอจนครบ
  3. อัพเดทพร้อมแล้ว (x.y.z) → กด รีสตาร์ทเดี๋ยวนี้ เพื่อติดตั้ง
ข้อควรระวังกดรีสตาร์ทขณะกำลังทำงาน จะเสียประวัติบนหน้าจอ (ข้อมูลที่สแกนแล้วยังอยู่ในระบบหลัก) ควรทำช่วงเว้นจากการสแกน หากไม่กด โปรแกรมจะติดตั้งให้ตอนปิดโปรแกรม

7แก้ปัญหาที่พบบ่อย

อาการตรวจสอบ / วิธีแก้
ยิงแล้วไม่มีอะไรเกิดขึ้นเลย1) บาร์โค้ดต้องยาวอย่างน้อย 5 ตัวอักษร 2) เครื่องสแกนต้องส่ง Enter ท้ายรหัส 3) ดู logs ว่ามีข้อความ “Scanner worker หยุดทำงาน” หรือไม่ ถ้ามี ให้ปิดแล้วเปิดโปรแกรมใหม่ 4) ลองพิมพ์รหัสในช่อง “พิมพ์หรือสแกน barcode” เทียบดู
การ์ดเป็น “ยังไม่พร้อม”เลือกจุดตรวจและ CNGroup ให้ครบ (ข้อ 2.2, 2.3)
ขึ้น “จุดตรวจไม่ตรงกัน…”รหัสท้ายบาร์โค้ดไม่อยู่ในจุดที่เลือก — เลือกจุดเพิ่มหรือตรวจว่าถือใบถูกจุดหรือไม่
ขึ้น “กรุณาระบุ Station ID ในบาร์โค้ด (CN.STATION_ID)”ป้ายบาร์โค้ดไม่มีรหัสจุดตรวจ ใช้ป้ายรูปแบบ CN.รหัสจุด
ขึ้น “คุณไม่มีสิทธิ์ SCAN_CREATE”แจ้งผู้ดูแลระบบให้เพิ่มสิทธิ์ให้บัญชีของคุณ
ถูกพาออกไปหน้าเข้าสู่ระบบเองเซสชันหมดอายุ (ข้อ 1.4) ล็อกอินใหม่ ค่าที่เลือกไว้ถูกล้าง
รายการจุดตรวจ/CNGroup ว่างเปล่าตรวจการเชื่อมต่อเครือข่าย ดู logs หา “โหลด … ล้มเหลว”
ไม่มีเสียงเสียงต้องเปิดที่ระดับเครื่อง (ข้อ 6.2) และเปิดลำโพง
พิมพ์ในโปรแกรมอื่นแล้วถูกนับเป็นสแกนการพิมพ์เร็วมาก (ตัวอักษรห่างไม่เกิน 50 มิลลิวินาที) แล้วกด Enter อาจถูกนับ — พิมพ์ช้าลงหรือหลีกเลี่ยงการพิมพ์ตัวเลขยาวติดๆ ระหว่างทำงาน
ไม่เห็นแจ้งเตือนมุมจอโปรแกรมที่เปิดเต็มจอแบบเอกสิทธิ์ (เช่น DirectX) อาจบังกล่อง ดูผลที่ logs แทน

Aตารางสิทธิ์ที่เกี่ยวข้อง

รหัสสิทธิ์อ้างอิงจากเส้นทาง (route) ของระบบหลักที่โปรแกรมเรียกใช้ในโฟลเดอร์ ex ของโปรเจค

รหัสสิทธิ์การทำงานในโปรแกรมที่ใช้สิทธิ์นี้
SCAN_CREATEสแกนโหมด Checkpoint, ยิง Recheck
SCAN_DELETEยกเลิกการสแกน (Checkpoint)
SCAN_UPDATEยกเลิก recheck

STATION_REMARK_DELETEลบหมายเหตุจุดตรวจ
REMARK_REASON_READโหลดรายการ “เหตุผล” ในฟอร์มหมายเหตุ
หมายเหตุการค้นหาผู้ป่วยในส่วนหมายเหตุ และรายการจุดตรวจ/CNGroup ในแผงเลือก ต้องล็อกอินเท่านั้น (จากโค้ดที่อ่านไม่พบการกำหนดรหัสสิทธิ์เพิ่มสำหรับสองส่วนนี้ แต่ยังไม่ได้ตรวจฝั่งระบบหลักทั้งหมด) ส่วน “บทบาทมาตรฐาน” ว่าบทบาทใดมีสิทธิ์ใดบ้างกำหนดที่ระบบหลัก คู่มือนี้ยังไม่ยืนยัน

Cคำถามที่พบบ่อย (FAQ)

ปิดโปรแกรมแล้วเปิดใหม่ ต้องเลือกโหมด/จุดตรวจ/CNGroup ใหม่ไหม?

ไม่ต้อง หากยังไม่ได้ออกจากระบบ โปรแกรมจำไว้ แต่ “ออกจากระบบ” หรือ “เปลี่ยนโหมด” จะล้างค่าที่จำไว้

สแกนผิดคน ทำอย่างไร?

กด ยกเลิก ที่รายการนั้น (บทที่ 3.6) แล้วยิงคนที่ถูกต้อง ต้องมีสิทธิ์ SCAN_DELETE

ทำไมยิงแล้วขึ้น “ซ้ำ” ทั้งที่เพิ่งยิงครั้งแรก?

อาจมีคนอื่นยิงไว้ก่อนแล้ว ข้อความจะบอกเวลาและชื่อผู้ยิงเดิม

ข้อมูลประวัติบนหน้าจอหายไปไหน?

ประวัติเก็บเฉพาะระหว่างเปิดโปรแกรมและสูงสุด 20 รายการ ข้อมูลจริงอยู่ในระบบหลัก

เลือกหลายจุดตรวจแล้วแต่ละบาร์โค้ดไปทุกจุดเลยไหม?

ไม่ใช่ ในโหมดที่ใช้งานอยู่ (Manual) การสแกนถูกส่งไปเฉพาะจุดที่ฝังในบาร์โค้ด จุดที่เลือกทำหน้าที่เป็นรายการอนุญาต

ใช้โหมด Auto ได้ไหม?

ตอนนี้ปิดใช้งานชั่วคราว ใช้ได้เฉพาะ Manual

มีคู่มือสำหรับผู้ดูแลระบบหรือไม่?

ไม่มีในเล่มนี้ ดูหัวข้อ 0.3

Dแนวปฏิบัติที่แนะนำ

  • ตรวจชื่อ CNGroup และจุดตรวจที่แสดงเป็นป้ายสีน้ำเงินทุกครั้งก่อนเริ่มกะ
  • เลือกจุดตรวจเฉพาะที่รับผิดชอบ เพื่อให้ระบบช่วยกันสแกนผิดจุด
  • ดูการ์ด “ผลล่าสุด” ทุกครั้งที่ยิง โดยเฉพาะป้าย “ซ้ำ” และ “ผิดพลาด” อย่าข้ามไป
  • ที่ Lab ให้เลือกจุดตรวจไว้ด้วยแม้ไม่บังคับ และสังเกตตัวเลข “รอเช็ค” ลดลงตามที่คาด
  • กรณี recheck ถูกปฏิเสธ ให้แจ้งหน้างาน/ทะเบียนทันที ไม่พยายามสร้างรายการเอง
  • ออกจากระบบทุกครั้งเมื่อเลิกใช้เครื่องที่ใช้ร่วมกัน
  • เก็บภาพแผง logs ไว้เมื่อต้องแจ้งปัญหา แต่อย่าส่งต่อภายนอกเพราะมีข้อมูลผู้ป่วย
